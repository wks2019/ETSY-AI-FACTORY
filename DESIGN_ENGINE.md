# PURPOSE

The Design Engine defines the visual identity of every product created by the ETSY-AI-FACTORY.

Every product must look like it belongs to the same premium brand.

The Design Engine exists to eliminate inconsistent layouts, random design choices and amateur presentation.

---

# DESIGN PHILOSOPHY

Every page should communicate:

Luxury

Clarity

Elegance

Functionality

Professionalism

Timelessness

Less is more.

Whitespace is a design element.

Function comes before decoration.

# GRID SYSTEM

Use:

8-point spacing system

Consistent margins

Consistent gutters

Consistent alignment

Predictable spacing

No random positioning.

---

# WHITESPACE

Whitespace is mandatory.

Every page should breathe.

Never fill empty space simply because it exists.

---

# TYPOGRAPHY

Use Canva-supported fonts only.

Maximum:

2 font families

3 font weights

4 font sizes

Consistent hierarchy.

Avoid decorative fonts for body text.

---

# COLOUR

Use only colours defined in COLOR_SYSTEM.md.

Every colour requires a purpose.

Avoid random colour choices.

---

# ICONS

Icons must be:

SVG

Commercial-use

Minimal

Consistent

Simple

Editable

One icon style per product.

---

# ILLUSTRATIONS

Illustrations should support content.

Never dominate content.

Prefer:

Line art

Minimal graphics

Soft geometric elements

Elegant dividers

Subtle botanical elements where appropriate

Avoid trendy graphics that will quickly date the product.

---

# PAGE COMPOSITION

Every page should contain:

Primary focus

Secondary information

Writing area

Whitespace

Visual balance

Navigation where required

---

# DESIGN REVIEW

Before approval ask:

Does it look premium?

Does it look modern?

Does it look luxurious?

Does it improve usability?

Does it fit the brand?

Would a customer immediately trust this product?

If any answer is "No"

Continue refining.

---

# FINAL DIRECTIVE

The Design Engine is responsible for perceived value.

Customers often decide whether to purchase within seconds based on appearance.

Every design decision must increase trust, improve usability, reinforce the brand, and support long-term scalability across the ETSY-AI-FACTORY catalogue.
