# 0. AUTHORITY AND SCOPE

This document defines **who the brand is**. It does not define what colours or fonts express it.

| Question | Answered by |
|---|---|
| Who are we, for whom, and how do we sound? | This document |
| Which exact colours, in which roles? | `systems/COLOR_SYSTEM.md` |
| Which faces, weights, sizes, and scale? | `systems/TYPOGRAPHY_SYSTEM.md` |
| How is a Business Planner built? | `products/_STANDARDS/BUSINESS_PLANNER_STANDARD.md` |

No hex value and no font size appears in this file. Where a rule needs one, it references the owning document.

## 0.1 Open decision — brand name

**The brand has no customer-facing name.** `ETSY-AI-FACTORY` is the repository, `wks2019` is the shop handle, and "The Ultimate Collection" is one product line.

A brand system cannot be finished without a name, because §8 and §9 depend on it. Until it is decided, this document uses `{BRAND}` as a placeholder and every rule referencing it is provisional.

**Requirements when choosing:** pronounceable, spellable on hearing, available as a domain and as an Etsy shop name, not tied to a single product category, and still appropriate when the catalogue includes journals and printables rather than only planners.

# 1. BRAND MISSION

To make the tools of organised work feel worth using.

Most planning products fail their buyer twice: they look amateur, and they are built for a customer the designer imagined rather than one who exists. {BRAND} exists to remove both failures — to produce planning tools with the visual standard of a design studio and the functional standard of software.

---

# 2. BRAND VISION

A catalogue where any two products, opened side by side, are recognisably from the same house — without a logo being visible.

Within three years: the reference point buyers compare other planners against, across planners, journals, and printables, in every English-speaking market.

---

# 3. BRAND VALUES

| Value | What it means in practice | What it rules out |
|---|---|---|
| **Function first** | Every page completes a task the customer already performs | Decorative pages, filler, quote pages |
| **Restraint** | The best version has fewer elements, not more | Ornament, gradient, trend styling |
| **Clarity** | The customer never wonders what a page is for | Ambiguous labels, unexplained icons |
| **Durability** | The product looks current in five years | Trend colours, dated illustration, fashion typography |
| **Honesty** | The listing describes exactly what is delivered | Inflated page counts, misleading mockups, stock imagery of a different product |
| **Craft** | Details the customer will never consciously notice are still correct | Uneven spacing, orphan headings, unaligned rules |

Values resolve conflicts. When two design options are equally valid, choose the one that better serves the value higher in this table.

# 4. TARGET MARKET

## 4.1 Primary

| Attribute | Definition |
|---|---|
| Who | Working adults who organise their own time and money |
| Age | 25–55 |
| Markets | US, UK, CA, AU — English-speaking, in priority order |
| Context | Solo founders, freelancers, consultants, professionals, students in later study |
| Devices | iPad with GoodNotes or Notability; or home/office printer |
| Price sensitivity | Low. Will pay a premium for something that works |

## 4.2 Defining behaviour

This customer **has already abandoned at least one planner**. That is the single most useful fact about them.

They abandoned it because it was cramped, because navigation failed, because printing broke, or because it was built for someone else's life. Every design decision should be tested against: *is this the thing that makes them stop using it?*

## 4.3 Explicitly not the market

- Buyers seeking novelty, character licensing, or seasonal aesthetics
- Buyers seeking the cheapest available file
- Buyers wanting a fully bespoke, one-off commission

Declining a market is a positioning decision, not a loss.

# 5. PRODUCT POSITIONING

## 5.1 Statement

For working adults who have abandoned planners that failed them, {BRAND} makes undated, hyperlinked planning systems with the visual standard of a design studio — unlike mass-market templates, which are built to be produced quickly rather than used daily.

## 5.2 Position

| Axis | Position |
|---|---|
| Price | Upper-mid. Above template floor, below bespoke |
| Aesthetic | Editorial minimal. Restrained, not stark |
| Function | High. Navigation and structure are the product |
| Voice | Professional peer, not coach |
| Dating | Undated by default. Evergreen catalogue, no annual reprint cycle |

## 5.3 Differentiators

Every product must deliver at least one, stated plainly in the listing:

- Navigation that works — every page reachable in one tap
- Generous writing space — the most common reason planners are abandoned
- Four sizes from one purchase
- Prints correctly at 100% without instruction
- Genuinely editable in Canva — live text, available fonts

# 6. BRAND PERSONALITY

| Trait | Expression |
|---|---|
| **Composed** | Nothing rushed, crowded, or shouting |
| **Precise** | Alignment and spacing are exact, not approximate |
| **Quiet** | The product does not perform. It works |
| **Warm** | Ivory rather than white; serif rather than clinical sans |
| **Adult** | Assumes competence. Does not instruct on how to feel |

**If the brand were a place:** a well-lit studio with one good desk.
**If the brand were a person:** the colleague whose documents are always correct and who never mentions it.

# 7. TONE OF VOICE

## 7.1 Principles

| Do | Do not |
|---|---|
| Say what the page is for | Say what the customer should feel |
| Use plain, specific nouns | Use aspirational abstractions |
| Write short sentences | Write in fragments for effect |
| Trust the reader | Over-explain or motivate |

## 7.2 By surface

| Surface | Register |
|---|---|
| Page labels | Noun phrases. "Meeting Notes", not "Let's Meet!" |
| Instructions | Imperative, numbered, no filler |
| Listing title | Descriptive and searchable. Keyword-led, still readable |
| Listing description | First two lines carry the hook — mobile truncates the rest |
| Licence | Direct and unhedged. Permitted, prohibited, nothing else |
| Customer messages | Courteous, brief, no exclamation marks |

## 7.3 Prohibited

Exclamation marks in product copy. Motivational quotes. Emoji in listings or on pages. "Boss babe", "hustle", "slay", "girl". Manufactured urgency. Claims that cannot be verified from the file itself.

# 8. NAMING CONVENTION

## 8.1 Product names

```
[Qualifier] + [Function] + [Format]
```

| Part | Rule | Example |
|---|---|---|
| Qualifier | Optional. Signals edition or scope | Ultimate, Essential, Complete |
| Function | Required. What it organises | Business, Wedding, Budget |
| Format | Required. What it is | Planner, Journal, Tracker |

Good: *Business Planner* · *Ultimate Digital Planner* · *Client Tracker*
Rejected: *The Boss Lady Life Organiser* · *Plan-It-All Pro* · *Your Best Year Yet*

## 8.2 Rules

- Maximum four words. Longer names fail as thumbnails.
- Title Case. No all-caps, no punctuation, no ampersands.
- No years, no dates. The catalogue is undated.
- No possessive second person. Not "Your".
- The name must remain accurate if the page count changes.

## 8.3 Editions

| Edition | Meaning |
|---|---|
| Essential | Reduced page set. Entry price |
| *(none)* | Standard. The reference product |
| Ultimate | Extended page set, all optional pages |
| Bundle | Multiple products, priced below the sum |

An edition is a scope change. A theme is not an edition — see §9.3.

# 9. PRODUCT FAMILY NAMING RULES

## 9.1 Hierarchy

```
{BRAND}
  └─ Collection        e.g. Business Collection
       └─ Product       e.g. Business Planner
            └─ Edition   e.g. Business Planner Ultimate
                 └─ Theme  e.g. Business Planner Ultimate · Dark
```

## 9.2 Collections

A collection is named for its customer's domain, never for a mood. *Business Collection*, not *The Focus Edit*.

One file per collection at `libraries/collections/<slug>.md` — see that directory's README for the binding rules.

## 9.3 Themes

A theme is a palette swap and nothing else. It changes no layout, no page count, no component. Named with a mid-dot after the product name.

A theme is a separate listing but not a separate product, and does not consume a slot in its collection.

## 9.4 Family test

Before a product joins a collection, all four must hold:

1. Same palette, same type pairing, same component set
2. Recognisable as a member with the title covered
3. Stands alone as a purchase
4. Cross-sells at least two other members

| Item | Pattern | Example |
|---|---|---|
| Product directory | `NN-kebab-case` | `02-business-planner` |
| Slug | kebab-case | `business-planner` |
| PDF | `{slug}-{size}.pdf` | `business-planner-a4.pdf` |
| Themed PDF | `{slug}-{theme}-{size}.pdf` | `business-planner-dark-a4.pdf` |
| Cover | `{slug}-cover.png` | — |
| Listing preview | `{slug}-listing-preview.jpg` | — |
| Mockup | `{slug}-mockup-{context}.jpg` | `business-planner-mockup-desk.jpg` |
| Package | `{slug}-v{version}.zip` | `business-planner-v1.0.zip` |
| Page id | kebab-case, repeats `-NN` | `monthly-03` |
| System doc | `UPPER_SNAKE.md` | `BRAND_SYSTEM.md` |

**Rules:** lower case for assets, no spaces, no dates, ASCII only. A filename reaches the customer — it is part of the product.

# 11. ICONOGRAPHY PRINCIPLES

**Current state: the catalogue uses no icons.** Product 1 ships none. This section governs the decision if that changes.

| Rule | Detail |
|---|---|
| Necessity | An icon is added only where a word fails — space, or repetition across many rows |
| Format | SVG. Vector, never raster |
| Style | Single stroke weight, no fill, rounded terminals |
| Consistency | One icon family per product. Never mix sets |
| Legibility | Readable at Half Letter scale, printed in greyscale |
| Colour | Inherits `ink` or `muted`. Never accent, never multicolour |
| Meaning | Never the sole carrier of meaning — always paired with a label |
| Licence | Commercial-use, documented in the product asset list |

**Default position: no icons.** A label is clearer, translates, and prints. The burden of proof sits with adding one.

---

# 12. ILLUSTRATION PRINCIPLES

| Rule | Detail |
|---|---|
| Role | Supports structure. Never decorates |
| Permitted | Hairline rules, geometric dividers, restrained botanical marks on covers only |
| Prohibited | Character illustration, clipart, hand-drawn styling, watercolour, trend graphics |
| Weight | Never competes with content for attention |
| Ageing | Rejected if it will read as dated in five years |
| Origin | Original or documented commercial licence. Never uncleared |

On interior pages, illustration is limited to rules and dividers. Writing space is the product; anything consuming it must justify the cost.

---

# 13. PHOTOGRAPHY GUIDELINES

Photography appears only in listing imagery and mockups — never inside a product.

| Rule | Detail |
|---|---|
| Content | The product, shown in use |
| Light | Natural, soft, single direction. No hard studio flash |
| Palette | Must sit inside the product palette. No competing colour |
| Surfaces | Wood, linen, paper, stone. Matte |
| Props | Maximum two, both plausible — a pen, a cup. Never a styled flat lay of unrelated objects |
| People | Hands only, if at all. No faces |
| Honesty | Must show the actual product. A mockup implying content that does not exist is prohibited |
| Consistency | One lighting and surface treatment across a whole collection |

The honesty rule outranks the aesthetic rules. A beautiful mockup of a page the buyer will not receive is a refund and a bad review.

---

# 14. WHITE SPACE RULES

White space is the brand's most visible asset. It is what separates this catalogue from a template.

| Rule | Detail |
|---|---|
| System | 8-point spacing. Every margin, gap and padding is a multiple |
| Margins | Scale proportionally to page size. Never fixed across sizes |
| Density | A page at capacity is over capacity. Reduce content, do not reduce spacing |
| Writing areas | Generous over compact. Cramped ruling is the leading cause of abandonment |
| Grouping | Related elements sit closer than unrelated ones. Proximity carries the grouping, not boxes |
| Emptiness | Empty space is never filled because it exists |

**Test:** if a page must be crowded to fit its content, the content is wrong — split the page or cut the content. Never tighten the spacing.

---

# 15. ACCESSIBILITY PRINCIPLES

| Rule | Detail | Owner |
|---|---|---|
| Body contrast | ≥ 7:1 against ground | `COLOR_SYSTEM.md` |
| Secondary contrast | ≥ 4.5:1 against ground | `COLOR_SYSTEM.md` |
| Colour independence | No state or category shown by colour alone | This document |
| Greyscale | Every page must remain fully usable printed in greyscale | This document |
| Minimum size | Body text legible at Half Letter — the binding constraint | `TYPOGRAPHY_SYSTEM.md` |
| Line length | Comfortable measure. Never full-width body text on A4 | `TYPOGRAPHY_SYSTEM.md` |
| Writing space | Sized for adult handwriting, not for fitting more rows | This document |
| Document structure | One bookmark per page, correctly ordered, for screen-reader and outline navigation | `BUSINESS_PLANNER_STANDARD.md` §14 |
| Live text | Text is never rasterised — it must remain selectable and machine-readable | `PROJECT_RULES.md` §6 |

Accessibility here is not compliance theatre. Greyscale legibility and colour independence are the same rules that make a product print cheaply and photocopy well — they serve every buyer.

# 16. PRINT DESIGN PRINCIPLES

| Rule | Detail |
|---|---|
| Output | Vector PDF. Live text. Embedded subset fonts |
| Scale | Prints correctly at 100%. Never requires "fit to page" |
| Margins | Inside the safe print area of consumer printers |
| Bleed | Not required. No design element depends on edge-to-edge printing |
| Ink economy | No large solid fills. `paper` is a light ground, not a printed block |
| Hairlines | Minimum 0.5pt. Thinner rules disappear on inkjet |
| Duplex | Layouts work printed double-sided on 100–120 gsm |
| Two-up | A5 and Half Letter impose cleanly onto A4 and US Letter |
| Verification | A new page type is physically printed and checked before first release |

The dark theme is the exception to ink economy and must carry a print-cost note in its listing.

---

# 17. DIGITAL DESIGN PRINCIPLES

| Rule | Detail |
|---|---|
| Navigation | Every page reachable in one tap from any page |
| Tap targets | Sized for a finger on a tablet, not a cursor |
| Index | Present, complete, and the first destination after the cover |
| Bookmarks | One per page, matching the page order |
| Link integrity | Zero dead targets. A broken link is a build failure |
| Annotation | Designed for GoodNotes, Notability, Noteshelf, Xodo |
| Ground | Never pure white — reduces screen glare in long sessions |
| File size | Kept low. A slow-opening file feels cheap |
| Canva | Imports with live text, resolved fonts, unshifted layout. Verified manually per build |

# 18. PREMIUM QUALITY STANDARDS

Premium is not a visual style. It is the absence of defects the customer can find.

| Standard | Threshold |
|---|---|
| Release score | ≥ 95/100 — `engines/QUALITY_ENGINE.md` holds the veto |
| Page count parity | Identical across all four sizes |
| Link integrity | Every internal link resolves |
| Bookmark parity | Outline count equals page count |
| Typography | ≤ 2 families, ≤ 3 weights, ≤ 4 sizes. No synthesised weights, no font substitution |
| Spacing | 8-point system, no ad-hoc offsets |
| Alignment | Grid-aligned. No overlap, no clipping |
| Export | Vector, live text, embedded subsets |
| Package | Complete. No empty or placeholder files |
| Copy | No spelling or grammar errors anywhere, including the licence |

**Commercial test, applied before release:** would I pay this price for this file? Would I recommend it by name? Does it beat the top-rated listing in its niche?

Any "no" returns the product to production.

# 19. CONSISTENCY RULES

| Element | Consistent across |
|---|---|
| Palette roles | Every product, every collection |
| Type pairing | Every product |
| Spacing system | Every product |
| Page architecture | Shared page types across products |
| Navigation model | Every product |
| Cover structure | Every product |
| Naming | Every product and file |
| Voice | Every page, listing, and message |

## 19.1 Permitted variation

Palette values within the defined roles. Page selection and repeat counts. Product-specific page types. Cover wording.

## 19.2 Prohibited variation

New palette roles. A third font family. A different spacing system. A different navigation model. A different cover structure.

**Test:** two products from different collections, covers removed, placed side by side — a stranger should identify them as the same publisher.

# 20. FUTURE EXPANSION RULES

| Rule | Reason |
|---|---|
| New categories inherit this document unchanged | A brand that needs amending per category is not a brand |
| New formats — journals, printables, cards — inherit §§1–19 | Format is not identity |
| A new collection requires a file in `libraries/collections/` before its first product | The catalogue map stays true |
| Themes never alter layout | A future theme cannot break a shipped product |
| Brand changes require evidence from real sales or real customer feedback | `PROJECT_RULES.md` §14 |
| Non-English markets adapt copy, never structure or palette | Localisation is translation, not redesign |
| A logo, when created, is added here and to `COLOR_SYSTEM.md` for clear-space and reproduction rules | Currently none exists |

## 20.1 Known gaps

| Gap | Consequence |
|---|---|
| No brand name | §8 and §9 are provisional |
| No logo or wordmark | Covers rely on typography alone — acceptable, but a mark would strengthen recognition |
| No shop-front identity | Etsy banner, avatar, and about copy undefined |
| No pricing framework | Positioning states "upper-mid" without figures |

Each is a decision, not an oversight. None blocks product production.

# 21. DEFINITIONS

| Term | Definition |
|---|---|
| **Brand** | The consistent identity every product inherits. Defined here |
| **Collection** | A group of products sharing a customer, an identity, and a bundle path |
| **Product** | A single sellable item with its own spec and listing |
| **Edition** | A scope variation — Essential, Standard, Ultimate, Bundle |
| **Theme** | A palette swap. Changes no layout, no page count, no component |
| **Spec** | The JSON document from which a product is rendered |
| **Page type** | A semantic kind of page — month, tracker, index |
| **Renderer** | The function producing markup for a page type |
| **Component** | A reusable layout element — tab bar, panel, calendar grid |
| **Standard** | A blueprint every product of one kind must follow |
| **System** | A canonical reference defining one dimension of the brand |
| **Undated** | Contains no year or fixed dates. Sells indefinitely |
