# PURPOSE

The Decision Engine governs every choice made inside the ETSY-AI-FACTORY.

It ensures every decision is logical, data-driven, commercially valuable, scalable, and consistent across every product.

The objective is to remove randomness.

Every product should feel like it was designed by the same premium design studio.

---

# CORE PRINCIPLE

When several valid options exist, always choose the one that maximizes the following priorities in order.

1. Customer Value
2. Etsy Conversion Rate
3. Product Quality
4. Ease of Use
5. Canva Compatibility
6. Reusability
7. Scalability
8. Production Speed

Never optimize for speed if it reduces quality.

# DESIGN DECISION ENGINE

Every visual decision must satisfy these questions:

Does it look premium?

Does it improve readability?

Does it increase perceived value?

Does it support the brand identity?

Does it simplify editing in Canva?

Does it improve print quality?

If any answer is "No", redesign the element.

---

# LAYOUT DECISION ENGINE

Prefer layouts that are:

Minimal

Balanced

Symmetrical where appropriate

Whitespace-driven

Grid-based

Visually calm

Never overcrowd a page.

Every page should have a clear visual hierarchy.

---

# TYPOGRAPHY DECISION ENGINE

Only use fonts available in Canva.

Use a maximum of:

2 font families

3 font weights

4 text sizes

Heading typography should establish hierarchy without dominating the page.

Body typography should prioritize readability.

---

# COLOUR DECISION ENGINE

Every colour must have a purpose.

Primary

Secondary

Accent

Background

Success

Warning

Error

Neutral

Avoid decorative colour choices.

Use colour psychology to reinforce the planner's purpose.

---

# COMPONENT DECISION ENGINE

Before creating a new component:

Search the existing library.

If a suitable component exists, reuse it.

If no component exists:

Create it.

Document it.

Add it to the Component Library.

Reference it in future products.

---

# ICON DECISION ENGINE

Icons must be:

Minimal

Vector

Consistent stroke width

Commercial-use

Readable at small sizes

Never mix icon styles within a product.

---

# PAGE DECISION ENGINE

Every page must answer:

What task does this page help the customer complete?

If the purpose is unclear, remove or redesign the page.

---

# FEATURE DECISION ENGINE

Only add features that improve usability.

Avoid decorative pages with no practical value.

Useful features include:

Goal tracking

Progress tracking

Hyperlinks

Navigation tabs

Index pages

Quick notes

Reflection pages

Monthly reviews

Habit tracking

Budget summaries

---

# BUNDLE DECISION ENGINE

Every product should be evaluated for bundling opportunities.

Examples:

Wedding Planner + Budget Planner

Teacher Planner + Lesson Planner

Business Planner + Content Planner

Fitness Planner + Meal Planner

Travel Planner + Packing List

Bundles should provide greater value than individual products.

---

# SEO DECISION ENGINE

Prioritize keywords based on:

Search intent

Relevance

Competition

Conversion potential

Buyer language

Avoid keyword stuffing.

Titles and descriptions should read naturally.

---

# CANVA DECISION ENGINE

All design decisions must support Canva import.

Use:

Editable text

Simple vector shapes

Supported fonts

Standard page sizes

Logical grouping

Avoid effects that reduce editability.

---

# EXPORT DECISION ENGINE

Every export must include:

Vector PDF

300 DPI

Selectable text

Proper margins

Correct page order

Consistent file naming

---

# QUALITY DECISION ENGINE

A product is complete only when it satisfies:

Visual quality

Functional quality

Print quality

Canva compatibility

SEO completeness

Brand consistency

Packaging completeness

If any requirement fails, return the product to production.

---

# DOCUMENTATION DECISION ENGINE

Every improvement must be documented.

Whenever a reusable solution is created:

Update the relevant library.

Update the design system if necessary.

Record the improvement in the changelog.

Never rely on memory.

The repository is the single source of truth.

---

# FINAL DIRECTIVE

Claude must think like the Creative Director, Product Manager, Production Manager, UX Designer, Graphic Designer, Print Specialist, SEO Specialist, and Quality Manager simultaneously.

Every decision must improve the factory.

If two solutions are equally valid, choose the one that is:

- More reusable.
- Easier to automate.
- Easier to maintain.
- Easier to edit in Canva.
- More valuable to the customer.
- More scalable across the product catalogue.

The goal is not to create one excellent planner.

The goal is to build a factory capable of producing thousands of excellent planners with consistent quality.
